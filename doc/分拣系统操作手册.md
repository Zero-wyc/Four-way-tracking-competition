# 自动化零件分拣系统 - 操作手册

## 文档信息
- **版本**: V2.0
- **日期**: 2026-05-09
- **适用硬件**: STM32F103C8T6 + TCS34725颜色传感器 + 4自由度机械臂

---

## 一、系统概述

本系统实现自动化零件分拣功能，通过TCS34725颜色传感器识别红/绿/蓝三色零件，控制机械臂完成抓取并按颜色分类放置到对应工位。

### 性能指标
| 指标 | 目标值 | 说明 |
|------|--------|------|
| 颜色识别准确率 | ≥95% | 3次采样众数+置信度验证 |
| 响应时间 | ≤500ms | 单次检测+验证 |
| 定位精度 | ≤±2mm | 机械臂坐标补偿 |
| 平均处理时间 | ≤10秒/件 | 从识别到放置完成 |

## 三、软件配置

### 3.1 参数配置文件
所有可调参数集中在 `z_sorting.h` 文件顶部：

```c
// 颜色识别参数
#define COLOR_DETECT_THRESHOLD      80      // 亮度阈值
#define COLOR_SAMPLE_TIMES          5       // 采样次数
#define COLOR_CONFIDENCE_THRESHOLD  60      // 置信度阈值(%)

// 机械臂坐标（根据实际标定调整）
#define GRAB_X_DEFAULT              120.0f  // 抓取X坐标
#define GRAB_Y_DEFAULT              0.0f    // 抓取Y坐标
#define GRAB_Z_DOWN                 25.0f   // 抓取高度

// 工位坐标
#define PLACE_RED_X                 100.0f  // 红色工位X
#define PLACE_RED_Y                 -50.0f  // 红色工位Y
#define PLACE_GRN_X                 100.0f  // 绿色工位X
#define PLACE_GRN_Y                 0.0f    // 绿色工位Y
#define PLACE_BLU_X                 100.0f  // 蓝色工位X
#define PLACE_BLU_Y                 50.0f   // 蓝色工位Y
```

### 3.2 工位配置
默认工位布局（俯视图）：
```
        前方(X+)
          |
    红(-50)---绿(0)---蓝(+50)
          |
        机械臂
```

## 四、操作指南

### 4.1 启动系统
1. 上电后系统自动初始化
2. 串口输出：`[分拣系统 V2.0] 初始化完成`

### 4.2 颜色校准（重要！）
在首次使用或更换环境光后执行：
```
发送命令: $SMODE20!
```
系统会自动采集环境光并建立白平衡基准。

### 4.3 运行分拣模式

| 命令 | 模式 | 说明 |
|------|------|------|
| `$SMODE11!` | 分拣红色 | 只抓取红色零件 |
| `$SMODE12!` | 分拣绿色 | 只抓取绿色零件 |
| `$SMODE13!` | 分拣蓝色 | 只抓取蓝色零件 |
| `$SMODE14!` | 自动识别 | 自动识别颜色并分类（推荐） |
| `$SMODE15!` | 查看统计 | 发送当前统计信息 |
| `$SMODE16!` | 停止分拣 | 紧急停止并归位 |

### 4.4 测试功能

| 命令 | 功能 | 说明 |
|------|------|------|
| `$SMODE21!` | 颜色准确率测试 | 测试识别准确率是否≥95% |
| `$SMODE22!` | 机械臂精度测试 | 测试三个工位定位 |
| `$SMODE23!` | 系统自检 | 检查传感器和机械臂状态 |

## 六、故障排除

### 6.1 颜色识别不准确
| 现象 | 原因 | 解决 |
|------|------|------|
| 识别率低 | 环境光变化 | 重新执行白平衡校准 |
| 红色误识别 | 阈值不合适 | 调整COLOR_DETECT_THRESHOLD |
| 响应慢 | 采样次数多 | 减少COLOR_SAMPLE_TIMES |

### 6.2 机械臂定位偏差
| 现象 | 原因 | 解决 |
|------|------|------|
| 放置位置偏移 | 坐标未标定 | 调整PLACE_X/Y参数 |
| 抓取不到 | Z高度不对 | 调整GRAB_Z_DOWN |
| 运动卡顿 | 速度过快 | 增加ARM_MOVE_TIME |

### 6.3 常见错误码
| 错误码 | 含义 | 处理 |
|--------|------|------|
| 1 | 颜色不匹配 | 检查零件颜色或切换自动模式 |
| 2 | 抓取失败 | 检查机械臂姿态和零件位置 |
| 3 | 放置失败 | 检查工位坐标 |
| 4 | 无零件 | 检查零件是否在检测区域 |
| 5 | 机械臂超时 | 检查舵机连接 |
| 6 | 置信度低 | 重新校准或改善光照 |

## 八、安全注意事项

1. **机械臂运动范围内禁止站人**
2. **抓取时确保零件固定**
3. **紧急情况下发送 `$SMODE16!` 停止**
4. **定期检查夹爪力度**
