## 一、系统架构

### 1.1 模块组成
```
┌─────────────────────────────────────────┐
│              主控制程序 (z_main.c)        │
├─────────────────────────────────────────┤
│  分拣系统 (z_sorting.c/h)                │
│  ├── 颜色识别模块 (TCS34725驱动)          │
│  ├── 机械臂控制 (逆运动学)               │
│  ├── 状态机管理                          │
│  └── 统计与报警                          │
├─────────────────────────────────────────┤
│  循迹系统 (z_sensor.c)                   │
│  ├── 四路红外传感器                      │
│  └── PID控制算法                         │
├─────────────────────────────────────────┤
│  底层驱动                                │
│  ├── I2C (颜色传感器)                    │
│  ├── PWM (舵机控制)                      │
│  ├── ADC (超声波)                        │
│  └── USART (串口通信)                    │
└─────────────────────────────────────────┘
```

### 1.2 数据流
```
TCS34725 → I2C → 颜色识别算法 → 状态机 → 机械臂控制 → PWM → 舵机
                      ↓
                统计信息 → USART → 上位机/日志
```

## 三、硬件维护

### 3.1 颜色传感器 (TCS34725)

#### 维护周期: 每周
- [ ] 清洁传感器光学窗口
- [ ] 检查I2C通信稳定性
- [ ] 验证检测距离（建议5-10mm）
- [ ] 记录RGB基准值变化

#### 故障诊断
```
现象: 读数全0
原因: I2C通信失败或供电异常
排查:
  1. 测量VCC=3.3V?
  2. SCL/SDA波形正常?
  3. 设备地址0x29响应?

现象: 读数饱和(65535)
原因: 积分时间过短或光照过强
解决: 增加积分时间或降低光照
```

### 3.2 机械臂舵机

#### 维护周期: 每月
- [ ] 检查舵机虚位（不应>1°）
- [ ] 测量实际扭矩
- [ ] 润滑关节轴承
- [ ] 校准零位角度

#### 精度标定流程
```
1. 机械臂归位
2. 命令移动到 (100, 0, 50)
3. 测量实际到达位置
4. 计算偏差 Δx, Δy, Δz
5. 更新 ARM_POS_COMPENSATE_X/Y/Z
6. 重复验证3次
```

### 3.3 超声波模块

#### 维护周期: 每月
- [ ] 清洁发射/接收面
- [ ] 检查测量精度（标准距离测试）
- [ ] 验证温度补偿（如有）

## 四、性能优化

### 4.1 识别准确率优化

#### 当前指标
- 目标: ≥95%
- 当前: ~97%（实验室环境）

#### 优化方法
1. **增加采样次数**
   ```c
   #define COLOR_SAMPLE_TIMES  7  // 从5增加到7
   ```

2. **调整置信度阈值**
   ```c
   #define COLOR_CONFIDENCE_THRESHOLD  70  // 从60提高到70
   ```

3. **环境光控制**
   - 避免直射强光
   - 使用漫射光源
   - 定期重新校准

### 4.2 处理速度优化

#### 当前指标
- 目标: ≤10秒/件
- 当前: ~8.5秒（优化后）

#### 时间分解
| 步骤 | 时间(ms) | 优化空间 |
|------|----------|----------|
| 移动到目标 | 2000 | 提高循迹速度 |
| 颜色检测 | 500 | 减少采样次数 |
| 验证颜色 | 750 | 并行处理 |
| 接近零件 | 500 | 合并动作 |
| 抓取 | 1500 | 使用动作组 |
| 移动到工位 | 1000 | 优化路径 |
| 放置 | 1500 | 使用动作组 |
| 返回 | 800 | 快速模式 |
| **总计** | **8550** | - |

#### 优化建议
1. 使用预存动作组替代逆运动学计算
2. 合并接近和抓取动作
3. 优化循迹路径减少移动时间

### 5.2 常见问题排查

#### 问题1: 颜色识别率下降
```
排查步骤:
1. 运行准确率测试 ($SMODE21!)
2. 检查环境光是否变化
3. 重新执行白平衡校准
4. 检查传感器窗口是否脏污
5. 验证零件颜色是否褪色
```

#### 问题2: 机械臂定位偏差
```
排查步骤:
1. 运行精度测试 ($SMODE22!)
2. 检查舵机零位
3. 测量实际坐标偏差
4. 更新补偿参数
5. 检查机械结构松动
```

#### 问题3: 抓取失败率高
```
排查步骤:
1. 检查夹爪闭合力度
2. 验证抓取坐标
3. 检查零件表面特性
4. 调整抓取高度
5. 测试超声波验证功能
```
